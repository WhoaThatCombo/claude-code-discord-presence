# Claude Code Discord Presence

Shows a Discord status while you use [Claude Code](https://claude.com/claude-code):

```
Playing ClaudeCode
🔥 293.0M tokens · 323.2k/min
🤖 3 agents: 2× general-purpose, 1× Explore
⏱ 1:36
```

- **Tokens**: everything sent to or generated by the model since midnight, across all sessions and subagents (includes cached input, which is why it's big).
- **Rate**: tokens per minute, averaged over the last 5 minutes.
- **Agents**: subagents working right now, grouped by type. Shows `N sessions · no subagents` or `idle` otherwise.

It **never shows what you're working on**: no prompts, file names or project names. It reads Claude Code's local transcript files (`~/.claude/projects`), turns them into numbers, and only those numbers go to Discord.

It starts automatically when a Claude Code session opens (terminal or the desktop app's Code tab) and clears itself about 30 seconds after the last one closes.

Works on Windows, macOS and Linux. Needs Python 3.9+ and the Discord desktop app.

## Easiest setup: let Claude do it

Clone this repo, open Claude Code in it, and say:

> Set up the Discord presence from this repo following the README.

## Setup instructions (for Claude Code, or do it by hand)

> **Claude:** follow these steps on the user's machine. Use absolute paths everywhere. Merge into existing settings, don't overwrite them. Tell the user what you changed.

1. **Install the dependency**
   ```bash
   python -m pip install pypresence
   ```
   Use whichever Python is on PATH (`python3` on macOS/Linux). Note the full path to that interpreter (`python -c "import sys; print(sys.executable)"`), since the hook needs it.

2. **Copy the script to a permanent folder**: `~/.claude/discord-presence/claude_presence.py`. Don't run it from a temp or clone folder that might get deleted.

3. **Test it** (prints the status without touching Discord):
   ```bash
   python ~/.claude/discord-presence/claude_presence.py --print
   ```
   You should see a token line and an agents/sessions line.

4. **Add a SessionStart hook** to the user's `~/.claude/settings.json`. Read the file first and merge into any existing `hooks` / `SessionStart` entries. Replace both paths with absolute paths for this machine (on Windows use forward slashes, e.g. `C:/Users/NAME/...`):
   ```json
   {
     "hooks": {
       "SessionStart": [
         {
           "hooks": [
             {
               "type": "command",
               "command": "/ABSOLUTE/PATH/TO/python",
               "args": ["/ABSOLUTE/PATH/TO/.claude/discord-presence/claude_presence.py", "--spawn"],
               "timeout": 15
             }
           ]
         }
       ]
     }
   }
   ```
   `--spawn` starts the presence loop in the background and returns right away, so it doesn't slow down session startup. Only one copy ever runs (it holds local port 47823 as a lock), so a new session doesn't start a duplicate.

5. **Start it now** without waiting for a new session, by running the same command the hook runs:
   ```bash
   python ~/.claude/discord-presence/claude_presence.py --spawn
   ```
   After about 15 seconds, check `~/.claude/discord-presence/presence.log`: it should say `Connected to Discord.`

6. **Discord side**: the user needs the Discord **desktop** app running and **User Settings → Activity Privacy → "Share your detected activities with others"** turned on. Right after Discord starts it can take a few minutes before apps can set a status; the script keeps retrying.

### Using your own Discord app (optional)

By default it uses a shared Discord app called **ClaudeCode** that already has the logo uploaded, so there's nothing to set up. To use your own name or image:

1. Create an application at <https://discord.com/developers/applications>. Its name is what shows as "Playing ___".
2. Under **Rich Presence → Art Assets**, upload a 1024×1024 image and save it.
3. Find the asset's key. Discord may auto-name it, so check here: `https://discord.com/api/v10/oauth2/applications/<APP_ID>/assets`
4. Set the environment variables `DISCORD_CLIENT_ID=<APP_ID>` and `DISCORD_ASSET=<asset key>` for the hook, or edit the two constants at the top of `claude_presence.py`.

## Commands

| Command | What it does |
|---|---|
| `python claude_presence.py --print` | Print the status once, without Discord |
| `python claude_presence.py --spawn` | Start in the background (what the hook runs) |
| `python claude_presence.py` | Run in the foreground, printing each update |

## Troubleshooting

- **Nothing shows up**: check `presence.log`. `DiscordNotFound` means Discord isn't running or isn't ready yet. Wait, or fully quit and reopen Discord.
- **Question mark instead of the logo**: the asset key is wrong. Check it with the URL in step 3 above.
- **Old name or picture**: Discord caches app info. Press Ctrl+R in Discord.
- **Turn it off**: delete the `SessionStart` hook entry from `~/.claude/settings.json`.
